# Инструкции для AI-агентов

## Язык общения

- Объясняй пользователю ход работы, найденные проблемы и результат по-русски, если пользователь не попросил другой язык.
- Имена команд, файлов, функций и фрагменты кода оставляй в оригинальном виде.

## О проекте

- `mathtool.py` — небольшой CLI-скрипт на Python для решения квадратных уравнений.
- Проект использует стандартную библиотеку Python и не содержит отдельного пакета, сборки или тестового набора.
- Пользовательский интерфейс и справка программы сейчас написаны на русском языке.

## Запуск и проверки

- Справка: `python mathtool.py --help`
- Интерактивное решение: `python mathtool.py solve`
- Решение с параметрами: `python mathtool.py solve -a 1 -b -3 -c 2`
- Проверка синтаксиса: `python -m py_compile mathtool.py`

После изменения `mathtool.py` запускай как минимум проверку синтаксиса и подходящую команду CLI для затронутого сценария. Если добавляются тесты, запускай их явно и не предполагай наличие тестового фреймворка без проверки.

## Правила изменений

- Сохраняй CLI-команды и русские сообщения, если задача явно не требует изменения публичного поведения.
- Предпочитай небольшие изменения в существующем скрипте; не добавляй зависимости и инфраструктуру без необходимости.
- Не перезаписывай пользовательские изменения в рабочей копии и не исправляй несвязанные проблемы.
- Для математической логики проверяй как минимум случаи с двумя корнями, одним корнем и отсутствием действительных корней, когда они затронуты изменением.
