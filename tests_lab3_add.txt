ОСТАЛЬНЫЕ ОБЯЗАТЕЛЬНЫЕ ПРОВЕРКИ БЕЗ ДОПОЛНИТЕЛЬНЫХ ВХОДНЫХ ФАЙЛОВ
Для каждого метода bubble, selection, insertion, counting выполнить обе команды:
python mathtool.py sort -m bubble --order asc
python mathtool.py sort -m bubble --order desc
Подставлять вместо bubble очередной метод. Для каждого запуска вводить один из наборов:
5 -2 5 0 -2       -> asc: -2 -2 0 5 5; desc: 5 5 0 -2 -2
-5 0 3 8         -> asc: -5 0 3 8; desc: 8 3 0 -5
8 3 0 -5         -> asc: -5 0 3 8; desc: 8 3 0 -5
7                -> в обоих направлениях: 7
После строки чисел нажать Enter и ещё Enter на пустой строке.
Каждый успешный запуск: сообщение «Массив отсортирован.» и код 0.

Пробелы/запятые и несколько строк: python mathtool.py sort -m counting
Ввести строку 24, -76, затем Enter; строку 81 43 -5; Enter; пустую строку.
Ожидается -76 -5 24 43 81 и сообщение об успехе, код 0.
Повторить, завершая строкой из пробелов; затем отдельно EOF (Ctrl+Z и Enter).

Ошибки данных: python mathtool.py sort -m counting
Отдельные запуски: сразу пустая строка; 1 abc 3; 1 2.5; 1 101.
После ввода завершить пустой строкой. Ожидаются ошибки количества/целого числа/диапазона, код 1.

Поиск с клавиатуры: python mathtool.py search -v 43
Ввести -76 -5 24 43 81 и пустую строку.
Ожидается индекс 4, код 0.

Повторяемость генерации: дважды выполнить
python mathtool.py fill -c 5 --seed 42
Оба раза ожидается 63 -72 -94 89 -30.

Неверные параметры генерации (каждая команда — отдельно, код 1):
python mathtool.py fill -c 0
python mathtool.py fill -c 1000001
python mathtool.py fill -c 5 --min -101
python mathtool.py fill -c 5 --max 101
python mathtool.py fill -c 5 --min 10 --max -10
Ожидаются сообщения о количестве, границах и порядке границ соответственно.

Ошибка чтения (файла специально не должно быть):
python mathtool.py sort -m bubble -i no_such_lab3_file.txt
Ожидается сообщение в stderr и код 1.
Ошибка записи (каталога специально не должно быть):
python mathtool.py fill -c 5 -o no_such_lab3_folder/result.txt
Ожидается сообщение в stderr и код 1.

Прежние команды: повторить сохранённый набор тестов первой/второй лабы.
Для stats ничего не менять: ввод завершается EOF, а не пустой строкой.

В .gitignore проверить строку .vscode/.
Для локального запуска F5 в .vscode/launch.json:

cwd: ${workspaceFolder}
args: ["sort", "-m", "bubble", "-i", "small.txt"]

ЗАМЕРЫ ВРЕМЕНИ — ЛАБОРАТОРНАЯ 3
Вставлять команды в PowerShell из корня проекта.
Данные уже приложены, но методичка требует создать их своей командой fill — поэтому сначала выполнить:

python mathtool.py fill -c 1000 --seed 1 -o data_1000.txt
python mathtool.py fill -c 3000 --seed 1 -o data_3000.txt
python mathtool.py fill -c 10000 --seed 1 -o data_10000.txt

Затем вставить весь блок ниже. Он делает 36 запусков: 3 размера × 4 метода × 3 повтора.
Каждый запуск заново читает исходный файл и сохраняет результат.
Копируй блок целиком, включая фигурные скобки. Это команды PowerShell, не код для Python-файла.
На 10000 чисел пузырёк и выбор могут работать заметно дольше; это ожидается.

foreach ($n in 1000, 3000, 10000) {
    foreach ($method in 'bubble', 'selection', 'insertion', 'counting') {
        foreach ($run in 1, 2, 3) {
            Write-Host "Размер $n; метод $method; повтор $run"
            python mathtool.py sort -m $method --order asc -i "data_$n.txt" -o "result_${n}_${method}_${run}.txt"
            if ($LASTEXITCODE -ne 0) { throw 'Сортировка завершилась с ошибкой' }
        }
    }
}

После этого сравнить все результаты для каждого размера (должно быть True):

foreach ($n in 1000, 3000, 10000) {
    $reference = Get-Content "result_${n}_counting_1.txt" -Raw
    foreach ($method in 'bubble', 'selection', 'insertion', 'counting') {
        foreach ($run in 1, 2, 3) {
            $same = (Get-Content "result_${n}_${method}_${run}.txt" -Raw) -eq $reference
            Write-Host "Размер $n; метод $method; повтор $run; совпадение: $same"
        }
    }
}
